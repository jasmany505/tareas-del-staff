# Seguridad

- Nunca publiques tokens de Discord, claves de bots, contraseñas ni secretos OAuth.
- No solicites la contraseña de Discord a los miembros del staff.
- Para una futura integración con Discord, utiliza OAuth2 oficial, variables de entorno y un servidor backend.
- Reporta vulnerabilidades de forma privada a los Owners.
- Redacta IP, correos y datos personales en logs o capturas antes de adjuntarlos.
