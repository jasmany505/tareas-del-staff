# Staff Tasks | Minecraft + Discord

Repositorio privado para organizar tareas del Staff de Minecraft y Discord.

## Instalación
1. Crea un repositorio privado llamado `staff-tasks` en https://github.com/new
2. Descomprime este paquete.
3. Sube TODO el contenido de la carpeta `Staff-Tasks-GitHub-FIXED` al repositorio, no la carpeta contenedora.
4. Conserva exactamente los nombres y las carpetas `.github` y `tareas`.
5. Ve a Settings → Actions → General y permite permisos de escritura para Issues si quieres que el workflow cree y aplique etiquetas.

## Flujo de tareas
- Crea una tarea desde Issues → New issue → Nueva tarea de Staff.
- Elige Minecraft, Discord o ambos, responsable, prioridad y fecha límite.
- Adjunta evidencia no sensible.
- Un encargado autorizado revisa y cierra el Issue cuando corresponda.

## Seguridad
No subas contraseñas, tokens de bots, claves API, archivos `.env` ni capturas de canales privados.
El repositorio privado solo es accesible para personas con permiso.
